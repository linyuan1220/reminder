        任务提醒 软件 · 使用说明
══════════════════════════════════════════════════════

一、这是什么
──────────────
任务提醒是一个在 Windows 后台运行的提醒小软件。
你用 Excel 表格填写"要提醒的事 + 周期 + 时间"，保存后，
程序到点就会自动弹出提醒窗口（强提醒红色闪烁、弱提醒蓝色、
错过提醒黄色闪烁，并配不同的提示音）。

二、文件说明（本文件夹）
──────────────
  任务提醒.exe      主程序（可执行文件，双击即可运行）
  提醒任务.xlsx     提醒任务表格（用 Excel 打开编辑）
  使用说明.txt      本说明文档

提示：几个文件应放在同一个文件夹里。程序会在自己所在文件夹中
直接读取"提醒任务.xlsx"，不用每次导入。
首次运行时，程序还会自动生成三个默认提示音文件：
  音效_强提醒.wav   音效_弱提醒.wav   音效_错过提醒.wav
（放在本文件夹，可自行替换成你喜欢的音频）

三、怎么用
──────────────
1. 把"任务提醒"文件夹放到你方便的位置（例如桌面或 D 盘），
   不要单独移动里面的文件。
2. 双击"任务提醒.exe"运行。首次运行会自动生成"提醒任务.xlsx"
   模板（若不存在）。
3. 用 Excel（或 WPS）打开"提醒任务.xlsx"，编辑表格：
   · 新增提醒：在表头下方空白行填写即可；
   · 修改提醒：直接改对应单元格；
   · 删除提醒：删掉那一行。
   保存后程序会在几秒内自动重新读取，无需重新导入。
   （周期类型、周几、每月几号、提醒时间、提醒强度都带下拉箭头，
   点击单元格右侧即可选择，也可手动输入，不易填错格式）
4. 程序一直在后台运行（缩到右下角系统托盘），到点弹窗提醒。
5. 关闭主窗口 = 隐藏到托盘（继续运行）。彻底退出：
   右键托盘图标 → "退出程序"。

四、Excel 表格怎么填（共 9 列）
──────────────
表格第一行是蓝色标题栏，第二行是各列表头，从第三行起填写你的任务。

  A列  提醒内容        要提醒的事，随便写，例如"喝水""开会"
  B列  周期类型        每天 / 每周 / 每月 / 每年 / 隔N天 / 指定日期（下拉）
  C列  周期数值(天)    仅"隔N天"填天数（如 2），其它留空
  D列  周几(每周)      仅"每周"填周几：周一~周日（下拉）
  E列  每月几号(每月)  仅"每月"填几号：1~31（下拉）
  F列  几月几号(每年)  仅"每年"填月日：如 10-13（10月13日）
  G列  起始/指定日期   "隔N天"填起始日期；"指定日期"填提醒日期
  H列  提醒时间        时:分，如 09:30（下拉常用时间，也可输入）
  I列  提醒强度        强 / 弱（下拉，可不填默认弱）

【各周期要填哪几列】
  每天        → 只填 H列 时间
  每周        → 填 D列 周几 + H列 时间
  每月        → 填 E列 几号 + H列 时间
  每年        → 填 F列 几月几号 + H列 时间
  隔N天       → 填 C列 天数 + G列 起始日期 + H列 时间
  指定日期    → 填 G列 具体日期 + H列 时间

【填写示例】
  提醒内容   周期类型   周期数值(天) 周几(每周) 每月几号 几月几号 起始/指定日期  提醒时间  提醒强度
  喝水       隔N天      2                                     2026-10-13    10:00     弱
  每周例会   每周                   周一                                 14:30     强
  发工资     每月                               15                            09:00     弱
  缴物业费   每年                                      10-01               09:00     弱
  每天午休   每天                                                          12:30     弱
  交房租     指定日期                                       2026-10-20     18:00     强

说明：
· 只有"每周/每月/每年/隔N天/指定日期"才需要填对应的 D/E/F/G 列，
  其它列留空即可；填错或缺了必填项，程序会跳过该行并在主窗口提示。
· H列时间留空默认按 09:00 提醒。
· F列几月几号写法示例：10-13、10/13、10月13日、1013 都行。

五、提醒音效（可自己选，可开关）
──────────────
打开主窗口，下方"提醒音效"区域可设置：

  · 启用提示音：勾选则弹窗时发声；取消勾选则静音。
  · 强提醒 / 弱提醒 / 错过提醒：每种可单独选择音频文件
    （点"选择音频…"选一个音频文件），也可点"重置"恢复为默认音效。

支持的音频格式：wav、mp3、ogg、flac 播放最稳定（推荐用这些）；
m4a、wma 等其它格式也会尽力播放。若你导入的文件确实无法播放，
建议先用格式转换工具转成 mp3 或 wav（最常见的两种，最可靠）。

默认情况下三种提醒就是不同的声音：
  强提醒  → 急促的双声
  弱提醒  → 一声轻响
  错过提醒→ 三声渐强的提醒音

提示：提醒弹出时，声音会一直循环播放，直到你在弹窗上点按钮确认
（"我知道了"/"稍后提醒"/"跳过本次"）才会停止，确保你不会漏掉。
如不需声音，取消勾选"启用提示音"即可。

六、提醒强度与"错过"提醒
──────────────
【提醒强度（I列）】
  强    → 到点时弹出红色窗口并红色闪烁，标题"重要提醒"，特别醒目
  弱    → 到点时弹出蓝色普通窗口，标题"到点提醒"（不填默认弱）

【错过的提醒】
  如果某个提醒到点时电脑没开机（程序没运行），等下次开机/打开程序后，
  这个错过的提醒会用一个【黄色闪烁】的窗口补弹出来，标题"错过的提醒"，
  让你不会漏掉。点"我知道了"后即恢复正常安排。

  窗口外观速览：
    错过的提醒  → 黄色闪烁
    强提醒      → 红色闪烁
    弱提醒      → 蓝色普通（不闪）

七、提醒窗口的三个按钮
──────────────
  我知道了       确认收到，程序自动安排下一次提醒
                 （循环任务=下一个周期，一次性任务=不再提醒）
  稍后提醒       过一会儿再提醒你，旁边可填分钟数
                 （默认10分钟，可填 1~1440 分钟）
  跳过本次       不确认，直接跳到下一次提醒（本轮不再打扰）

八、开机自动启动
──────────────
程序主窗口里有一个"开机自动启动"勾选框：
  · 勾选后，程序会写入系统自启动项，之后每次开机都会自动在后台运行；
  · 取消勾选，则取消开机自启。
首次运行程序时会弹窗询问是否设置开机自启，选"是"即可开启；
以后随时可在主窗口勾选/取消，无需重装。

九、系统托盘
──────────────
程序最小化后图标（一个金色铃铛）在屏幕右下角托盘区。
右键托盘图标可：
  显示主窗口      重新打开主界面
  打开提醒表格    用 Excel 打开任务表
  重新读取表格    手动刷新一次（通常自动刷新，无需手动）
  退出程序        彻底退出后台

十、安全与隐私（纯离线）
──────────────
本程序为纯离线工具：
· 程序只在你自己电脑上运行，不联网、不上传任何数据、
  不与外部任何服务器通信，你的提醒内容不会离开这台电脑。
· 代码层面已禁止网络连接，即使被调用也不会发出网络请求。

十一、常见问题
──────────────
Q：双击后没反应/看不到窗口？
A：程序已隐藏到托盘。看右下角托盘区有没有金色铃铛图标，
   双击或右键即可显示主窗口。

Q：改了表格但好像没生效？
A：保存表格后程序会在约5秒内自动重新读取。
   如果还不行，右键托盘图标→"重新读取表格"，或重启程序。

Q：程序会不会开机自启动？
A：默认不会。如需要，在"开机自动启动"打勾即可。

Q：能同时提醒多条吗？
A：可以。若同一时刻多条到期，会一条一条依次弹窗，处理完一条再弹下一条。

Q：提醒内容特别长，窗口显示不全？
A：弹窗会按内容长度自动加高，内容过长时会出现滚动条，可上下滚动看完全部内容，
   也可拖动窗口边缘放大。

Q：电脑没开机时到期的提醒怎么办？
A：下次开机打开程序后，这些"错过"的提醒会用黄色闪烁窗口补弹出来，
   确认后即恢复正常安排。

Q：提示音没声音？
A：先确认主窗口"启用提示音"已勾选；再确认电脑音量正常；
   若选了自定义音频却无声，可点"重置"用回默认音效。
